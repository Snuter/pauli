# User journey summary

Companion to [technical summary](concept-technical-summary.md); source is `docs/concept-user-journey.md`.[^user-journey]

# Vision

Make Open Access science from Europe PMC queryable by patients in plain language, without hallucination, with care for critical information.[^user-journey] See [vision](../overview/vision.md).

# Principles

Low energy, uncertainty, trust, honesty, safety, continuity — simplest wording by default, every fact cited, unknowns explicit, gates before critical content.[^user-journey] See [principles](../overview/principles.md).

# Journeys

* Unified Settings (Ollama setup, 1–5 buzzwords OR-union topic, per-term validation, full OA fetch, plus sensitivity/strictness/simplicity) — [settings](../workflows/onboarding-buzzwords.md).
* Asking: short `<150`-word cited answers or honest unknown with 3-way split — [asking](../workflows/asking-question.md).
* Simplicity slider only (10–15), same citations — [language](../workflows/language-toggle.md).
* Six gated categories, blur card, sensitivity profiles — [gating](../workflows/sensitive-gating.md).
* Follow topics, manual digest, library, 1-page doctor printout — [tracking](../workflows/tracking-doctor-visit.md).

# Good looks like

Short readable answers, gate before sensitive details at every slider setting, explicit unknowns, new-only sync, one-page printout.[^user-journey]
