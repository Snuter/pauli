    Initial Setup

    Ollama setup (once)

    Without the configured model (or cloud key for cloud) the app reports misconfiguration instead of answering.

    Retrieval strictness

    Threshold 0.0–0.6 (default 0.3). TOP_K=15 fixed. Separate from sensitivity.

    Context window: retrieved passages are placed into your Ollama model's context window — lower strictness sends more text and needs a larger window. Usable context size depends on the model (each model has a fixed maximum) and on your hardware (a local model needs enough RAM/VRAM to hold it; cloud models follow the provider's limits). If answers get cut off, turn incoherent, or everything gets very slow, raise strictness to send less context, or switch to a model with a larger context window on hardware that can hold it.

    Your topic (1–5 buzzwords, OR-union)

      Every asking session retrieves from this same shared corpus. No built-in default topics.

      Subscription email (optional)

      Optional setup. Only subscribed sessions are covered. One combined email per check, and only when new papers match a subscribed session (same strictness/TOP_K=15, new papers only). Delivery failures are shown here. Single-user, local only.
